# agents

This repository has all my agent-related stuff

It is the public, platform-neutral source for pinned Home Manager and Coder
consumers. See [`config/README.md`](config/README.md): deterministic offline
rendering, manifests, portable roles/policy, instructions and skill metadata.
Platform adapters, credentials and mutable owner UI choices stay with consumers.

- `opencode/plugins/`: OpenCode v2 server and TUI plugins, one package per directory.
  See [`opencode/plugins/README.md`](opencode/plugins/README.md).
