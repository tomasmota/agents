# Preservation-first compaction

An OpenCode V2 server plugin that changes the **local summarization policy**,
not the session lifecycle. It uses `session.hook("compaction")` and the session's
existing model, with no provider-specific API, separate model, automatic
handoff, or additional inference call.

## Policy

The checkpoint must contain all state necessary to continue correctly. High
signal means removing redundancy and obsolete activity, not imposing an
arbitrary short summary or a 15-file limit. The policy is in
[`instructions.js`](instructions.js).

It preserves user decisions and corrections, constraints, acceptance criteria,
decisions with rationale, failed approaches, uncertainty, verification gaps,
uncommitted and user-owned work, relevant external state, outstanding user
communication, evidence references, and executable next actions. Recoverable
bulk is replaced by precise references, not by guesses that important facts
can be rediscovered later.

OpenCode's summary headings are kept for compatibility. The plugin disables
tools only for the compaction request, keeps the model and generation settings,
and does not modify ordinary agent requests. It leaves a summary already
provided by another hook alone.

## Load

```jsonc
{
  "plugins": [
    "git+ssh://git@github.com/tomasmota/agents.git#main::path:opencode/plugins/compaction-preserve"
  ]
}
```

Update the installed Git package after deploying changes:

```sh
opencode plugin update 'git+ssh://git@github.com/tomasmota/agents.git#main::path:opencode/plugins/compaction-preserve'
```

## Limits

- A prompt is a preservation policy, not a proof that every necessary fact
  survives. Summaries are still generated by a model and are still lossy.
- This is not a fork of OpenCode's retained-tail serializer or its overflow
  recovery. Core request budgets and emergency reduction still apply.
- Information lost in an earlier compaction cannot be recovered by this hook.
- Native provider checkpoints are provider-controlled; this plugin is designed
  for OpenCode's default local-summary path.
- The plugin must not store or log conversation contents, credentials, or
  binary payloads. Summaries should refer to credential locations, never
  credential values.

## Test

```sh
npm ci --ignore-scripts
npm test
```

Fixtures are fictional. Unit tests validate request transformations and
lifecycle without making model requests. They do not measure a provider's
summary fidelity.
